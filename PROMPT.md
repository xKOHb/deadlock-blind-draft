# Промт для следующей ИИ / нового чата: проект «Deadlock Minigames»

Ты продолжаешь работу над сайтом. Весь сайт лежит в одном файле `index.html` (React 18 UMD + htm, Tailwind CDN, Firebase Realtime Database 8.10.1). Рядом лежат `favicon.svg` и `og.png`. Общайся с автором по-русски, коротко и без воды.

## ПРАВИЛА РАБОТЫ (обязательно)
1. Прежде чем править, прочитай присланный `index.html` целиком. Не переписывай сайт с нуля, делай точечные правки.
2. После КАЖДОЙ порции правок отдавай автору обновлённые файлы и обновлённый `PROMPT.md`. В нём должен быть актуальный список «Что уже сделано» (этот же текст с этими же правилами сохраняй в файле всегда).
3. Не добавляй на сайт значок шифа (маленькая иконка персонажа Shiv/«заточка» в углу иконок предметов из игры). Его на сайте быть не должно.
4. Не выдумывай данные предметов. Если не уверен, скажи об этом автору.
5. Автор не программист: объясняй простыми словами, что поменялось и что нужно сделать руками (например, заменить `YOUR-DOMAIN`).

## О проекте
- Главная страница = хаб выбора мини-игры (`Hub`). Адрес `#draft` открывает «Слепой драфт», пустой hash открывает хаб. Заголовок сайта нажимается и ведёт в хаб.
- Мини-режимов сейчас два: «Слепой драфт» (`#draft`) и «Чёрный аукцион» (`#auction`, рабочее название, автор может переименовать). Режимы добавляются в массив `games` внутри `Hub`, а адреса в `HASH_GAME` и `GAME_NAME`. Сайт это режимы ДЛЯ ИГРЫ в Deadlock (не «по мотивам»).
- «Слепой драфт» (Deadlock): игроки по очереди загадывают друг другу по 3 карты предметов, выбирают одну вслепую. Режимы: «Баланс» (тир раунда общий) и «Хаос» (тир выбирает сам игрок). Онлайн через Firebase (`games/{CODE}`) или локально на одном экране. Сайт ЛИШЬ помощник: настоящий бой 1 на 1 идёт в игре, поэтому сайт НЕ объявляет победителя и не пишет «ничья».
- Каталог предметов грузится из Deadlock Assets API (`api.deadlock-api.com/v1/assets/items`, на английском и русском), кэш в localStorage (`bd_catalog`, версия v:2).

## Что уже сделано
- Убран сильный оранжевый фильтр на карточках: фон светлый кремовый с лёгким оттенком цвета категории (оружие/спиритизм/живучесть).
- Тир предмета в правом верхнем углу карточки (римская цифра в цветном треугольнике, шрифт с засечками, чтобы «I» не походил на «!»).
- При наведении карточка увеличивается и подсвечивается; то же для предметов в инвентаре. Всплывающее описание считает свою реальную высоту и стоит рядом с курсором.
- Описание предмета разбито на: постоянные статы, блок «Пассивное/Активное» с перезарядкой, текст, плитки условных бонусов, строки «длительность / окно применения». Единицы: «mm» превращается в «m/s», русские единицы «м/с», «с».
- Разбор берёт `tooltip_sections` из API (формат не проверен вживую). Поверх него словарь `ITEM_FIX` (по английскому названию) с ручными данными для Active Reload, Extra Spirit, Arcane Surge. Остальные предметы автор пока не проверял; при расхождениях с игрой дополняй `ITEM_FIX`.
- Шрифты предметов: названия в описании Russo One, тексты описаний и названия на карточках Rubik (нормальная кириллица). Шрифт самого сайта не менялся.
- Выбранные для загадывания предметы показываются нормальными мини-карточками (иконка, цена, тир).
- Итоги: победитель не показывается ни в «Балансе», ни в «Хаосе». Заголовок «Драфт завершён», подпись «Предметы выбраны. Удачи!». Суммы душ у игроков остаются.
- Название вкладки «Deadlock Minigames», иконка вкладки (золотой ромб), мета-теги Open Graph для карточки-приглашения в Telegram/Discord (картинка `og.png`; адрес сайта уже подставлен: https://deadlock-games.vercel.app (хостинг Vercel, код лежит на GitHub xKOHb/deadlock-blind-draft)).
- Внизу сайта вместо подсказки про правую кнопку мыши стоит пометка: сайт сделан с помощью ИИ и описания могут не совпадать с игрой (было лень проверять каждый предмет). Эту фразу не убирать.
- Подвал с пометкой «неофициальный фанатский проект, Valve» на русском и английском сохранён.

- Хаб оформлен живее: иллюстрации у карточек, плашки, раздел «Частые вопросы» (массив `FAQ`, ответы сразу под вопросами).
- Шестерёнка справа вверху открывает настройки: язык названий (по умолчанию EN), язык описаний (по умолчанию RU), музыка вкл/выкл, трек, громкость, анимации, сброс. Настройки лежат в localStorage `bd_prefs2` (значения по умолчанию в `PREF_DEF`).
- Музыка генерируется в браузере через WebAudio (3 трека в `GEN_TRACKS`). Настоящие саундтреки Deadlock не вшиты (авторские права), свои mp3 можно добавить в `FILE_TRACKS`.
- «Чёрный аукцион»: игрок выставляет предмет, соперник ставит первым, дальше перебивают, «Пас» завершает торг (победитель платит последнюю ставку; если никто не ставил, предмет бесплатно уходит выставившему). Потом роли меняются. Бюджет и число предметов настраиваются. Правила в одной функции `auReduce`, она работает и локально, и онлайн (транзакции Firebase, путь `auctions/{CODE}/state`). Победитель не объявляется.
- ВАЖНО: в правилах Firebase Realtime Database должен быть разрешён путь `auctions` (так же, как `games`), иначе онлайн-аукцион не заработает (локальный режим работает всегда).
